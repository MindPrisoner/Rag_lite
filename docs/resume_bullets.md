# 简历项目描述

## 版本 A：算法 / 应用工程岗位通用版
- 搭建轻量级中文 RAG 问答系统，基于 BM25 + jieba 实现多文档检索，并结合 OpenAI 兼容大模型完成答案生成与来源引用输出。
- 设计文档加载、段落级分块、检索、提示词拼接、答案生成、日志记录的完整链路，支持 CLI、FastAPI 与 Gradio 三种交互方式。
- 针对早期固定长度切分导致的片段断裂问题，改进为按段落优先分块并保留 source / chunk_id 元信息，提升检索结果可读性与展示效果。

## 版本 B：更偏工程化版
- 独立实现轻量级 RAG 原型系统，完成知识库加载、BM25 检索、上下文增强生成、查询日志记录及服务化接口封装。
- 基于 FastAPI 构建 `/query` 接口，基于 Gradio 搭建可视化 Demo，支持答案展示、来源展示、检索结果调试与错误状态返回。
- 在资源受限环境下放弃重型本地向量依赖，改用轻量检索方案完成原型落地，兼顾环境成本、可维护性与演示效果。

## 版本 C：更偏求职展示版
- 从零构建可展示的 RAG Demo，支持多文档知识库问答、来源引用、API 调用与前端页面展示。
- 将大模型调用、检索、日志、配置管理拆分为独立模块，形成结构清晰、可复用、适合上传 GitHub 的工程项目。
- 完成项目 README、环境配置、启动脚本与敏感信息隔离，满足作品集展示与后续扩展需求。
