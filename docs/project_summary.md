# 项目摘要

## 一句话版本
一个基于 BM25 检索 + OpenAI 兼容大模型生成的轻量 RAG 系统，支持多文档知识库问答、来源引用、FastAPI 接口、Gradio 可视化和查询日志记录。

## GitHub 仓库描述（短）
轻量级中文 RAG Demo，支持多文档检索、来源引用、FastAPI API、Gradio 页面与查询日志。

## 项目定位
这是一个面向学习、求职展示和后续扩展的 RAG 原型项目，重点不是追求最强检索效果，而是用较低环境成本打通检索增强生成、服务化、日志记录和前端展示的完整链路。

## 项目亮点
1. 避开重型本地向量依赖，采用 BM25 + jieba 快速搭建轻量检索原型
2. 支持多文档知识库检索，并为每个检索片段保留 source / chunk_id 元信息
3. 回答中保留来源引用，便于调试、展示与结果可信度说明
4. 同时提供 CLI、FastAPI、Gradio 三种使用方式
5. 自动记录查询日志，便于后续分析检索和生成表现
