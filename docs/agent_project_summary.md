# LangGraph 多工具研究助手项目摘要

## 一句话简介

基于 LangGraph 构建的多工具 Agent 工作流系统，支持知识库问答、文档总结、文档对比、模糊请求澄清、多轮记忆、FastAPI 接口和 Gradio 展示页面。

## 项目定位

本项目是在 RAG Lite Demo 的基础上继续扩展的 Agent 工程化项目。  
目标不是做一个完全开放式的自由 Agent，而是先构建一个可控、可解释、可调试的多工具工作流系统。

## 核心能力

1. 任务路由：根据用户请求自动选择合适工具
2. RAG 问答：基于本地知识库回答问题
3. 文档总结：对指定知识库文档进行摘要
4. 文档对比：比较两个文档的重点和差异
5. 澄清节点：当用户请求模糊时，不盲目执行，而是请求补充信息
6. 多轮记忆：基于 thread_id 保留短期对话状态
7. 服务化：提供 FastAPI 接口
8. 可视化：提供 Gradio 页面用于演示

## 技术栈

- Python
- LangGraph
- FastAPI
- Gradio
- BM25
- jieba
- OpenAI 兼容 API
- Pydantic

## 项目价值

这个项目体现了从 RAG 到 Agent 工作流的完整过渡：  
先完成检索增强生成，再加入工具路由、状态管理、多轮记忆、错误回退和可视化展示，形成一个可演示、可扩展的 LLM 应用原型。
